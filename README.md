# Ammonia Storage Safety Risk Analysis

## Project Overview
This project presents a comprehensive safety and risk analysis of an ammonia storage system used in chemical and fertilizer industries. The study focuses on identifying potential hazards, evaluating associated risks, and recommending mitigation measures to improve process safety.

## Objectives
- Identify potential hazards in ammonia storage operations.
- Perform Failure Mode and Effects Analysis (FMEA).
- Evaluate risks using a Risk Matrix.
- Develop Risk Assessment Charts.
- Recommend safety and mitigation strategies.

## Methodology
- Process Description
- Hazard Identification
- FMEA Analysis
- Risk Assessment
- Risk Matrix Evaluation
- Safety Checklist
- Mitigation Strategies

## Tools Used
- Microsoft Word
- Microsoft Excel

## Key Findings
- Tank corrosion was identified as the highest-risk failure mode.
- Ammonia leakage can result in significant safety and environmental consequences.
- Preventive maintenance and monitoring systems are essential for risk reduction.
